# 📉 Customer Churn Prediction

## 1. Project Overview
Customer Churn Prediction is a machine learning project focused on identifying customers who are likely to stop using a company's products or services.

The project uses customer-related data to analyze churn behaviour and develop predictive models that can help businesses understand customer retention challenges.

Two machine learning algorithms, Logistic Regression and Decision Tree, are used to predict customer churn and evaluate model performance.

## 2. Why This Data Was Analyzed
Customer retention is important for business growth.

When customers stop using a company's services, businesses may experience revenue loss and reduced customer engagement.

Analyzing customer data helps identify patterns associated with churn and provides insights that can support customer retention strategies.

This project was developed to explore how machine learning can help predict potential customer churn.

## 3. Project Objectives
- Understand customer churn behaviour.
- Inspect and preprocess customer data.
- Identify important customer-related patterns.
- Build machine learning classification models.
- Predict whether a customer is likely to churn.
- Compare Logistic Regression and Decision Tree models.
- Evaluate model performance using classification metrics.

## 7. Machine Learning Algorithms

### A. Logistic Regression
A supervised machine learning classification algorithm used to predict the probability of a customer belonging to a churn or non-churn category.

### B. Decision Tree
A supervised machine learning algorithm that uses decision rules to classify customers based on their input features.

## 8. Model Evaluation Metrics
The models were evaluated using:

- **Accuracy:** Measures the overall percentage of correct predictions.
- **Precision:** Measures how many predicted churn cases were actually churn cases.
- **Recall:** Measures how many actual churn cases were correctly identified.
- **F1-Score:** Combines precision and recall into a single performance measure.
- **Confusion Matrix:** Displays correct and incorrect classification results.

## 9. Model Evaluation Results

### Decision Tree
- Accuracy: 79.77%
- Precision: 63.36%
- Recall: 56.42%
- F1-Score: 59.69%

Logistic Regression was also evaluated and compared with the Decision Tree model.
